# 静态图 → 无缝循环动态壁纸（4K）

## 一、什么时候用这条路

用户把**一张竖图或方图**交给你，要「动态壁纸 / 会动 / 循环播放」，目标平台是 Wallpaper Engine（或手机动态壁纸）。

先用三条判断：

1. **有没有足够的显存跑 i2v 视频模型？** 8 GB 级显卡跑 14B 以上的图生视频模型不现实（模型本身就要 8–20 GB）。不现实就走本页的程序化路线，不要硬跑，也不要先试半小时再回退。
2. **要的是「画面里的东西动」还是「镜头在动」？** 本页只能做镜头与氛围层（推近、平移、飘雪、光晕）。人物转身、头发飘、衣服摆动这类**内容级运动**做不到——真需要就走 i2v 或 Live2D，本页不适用。
3. **原图够不够大？** 4K 输出要求原图长边 ≥1200 px。832×1248 这类图放大到 2160 高约 1.7×，可接受；小于 700 px 的会糊，先说明再动手。

## 二、构图只有一条铁律

**清晰区的遮罩必须在「图内」就衰减到 0。**

具体做法：主体按画布高度缩放（约 0.99H）后，叠一个椭圆径向遮罩，参数按**归一化半幅**给：

```
cx=0.50, cy=0.50, rx=0.52, ry=0.57, plateau=0.46
alpha: r<=plateau → 255；r>=1.0 → 0；之间 smoothstep
```

⚠️ `rx`、`ry` 一旦 ≥0.5，椭圆在图片左右边界处 `r` 仍 <1，alpha 还剩 70+，于是主体左右各留一条**竖直硬边**，整张图看起来像贴上去的矩形面板。这是本页最容易犯的错，已经犯过两次（0.62 和 0.78 各一次）。

配套第二条：**清晰层和虚化层的亮度要一致。** 背景若压暗（×0.72 之类），即使遮罩是软的，明暗差也会把矩形轮廓勾出来。要压暗就连主体一起压（全局 vignette），别只压背景。

## 三、流水线（顺序不能换）

1. 读图 → 生成**虚化床**：按 cover 缩放（`max(W/sw, H/sh)`，再 ×1.06 留视差余量）→ `GaussianBlur(22)` → 亮度 ×0.86。
2. 生成**清晰主体**：高 0.99H、等比宽度 → RGBA → 叠椭圆遮罩。
3. 生成**光晕层**：1600×1600 画 24 层同心椭圆（半径上限必须 < 800，否则在贴图边界被裁出一条方形硬边）→ `GaussianBlur(90)` → 预渲染 6 个强度档。
4. 逐帧：床层平移裁切 → 主体 affine（缩放 + 位移，`fillcolor=(0,0,0,0)`）→ 雪花 → 光晕 → vignette → RGB。
5. PyAV 编码。

## 四、无缝循环是算出来的，不是试出来的

所有运动必须写成 `2π·t`（t = 帧号 / 总帧数）的**周期函数**，且周期整除总帧数：

| 层 | 运动 | 周期 |
|---|---|---|
| 床 | x ±26 px、y ±14 px | 1 个循环 |
| 主体 | 缩放 1.00→1.022→1.00、x ±9 px、y ±11 px | 1 个循环 |
| 雪花 | 匀速下落 + 横向漂移，坐标 `% W`、`% (H+200)` 取模 | 自动闭合 |
| 光晕 | 6 档按 `sin` 轮转 | 1 个循环 |

渲染**不要**在最后一帧回退到第一帧（会顿一下）。直接渲染满 N 帧，第 N 帧与第 0 帧自然重合。

验收标准：解出首帧与末帧，逐像素差的均值 **< 3/255**（本机实测 1.37）。

## 五、参数（本机实测，24 fps / 20 s / 480 帧）

| 项 | 值 |
|---|---|
| 分辨率 | 3840×2160（16:9，Wallpaper Engine 桌面标准） |
| 帧率 / 时长 | 24 fps / 20 s（480 帧） |
| 编码 | `libx264`、`crf 19`、`preset medium`、`profile high`、`level 5.1`、`yuv420p` |
| 渲染耗时 | 1.4 s/帧（480 帧约 11 分钟） |
| 成品大小 | 13.9 MB |

手机竖屏就把 W/H 对调为 2160×3840，并相应改主体高度与遮罩——不要只旋转输出。

## 六、交付口径

- 文件放 `Desktop\ai图\壁纸_<角色>_<场景>_4K.mp4`。
- 明说三件事：分辨率/帧率/时长、循环是无缝的（给首末帧差值）、以及**导入方法**：Wallpaper Engine → 右下「创建壁纸」→ 选「视频」→ 拖入 mp4 → 保存；或资源管理器右键「用作壁纸」。
- 同步说明：这一版是**镜头级运动**，人物本身不会动。

## 七、红线

1. 不把清晰主体直接 `paste` 到虚化床上（必然是贴图感）。
2. 遮罩半径不 ≥0.5；光晕半径不 ≥贴图半宽。
3. 不在最后一帧做「回退帧」。
4. 不声称做了 i2v 或人物动画。
5. 脚本参数与耗时写进交付说明，方便用户自己换图重跑。

脚本：`scripts/make_wallpaper.py`，用法 `python make_wallpaper.py <源图> <输出mp4> [只渲N帧]`。
推导与实测数据见 `references/motion-and-composition.md`。
