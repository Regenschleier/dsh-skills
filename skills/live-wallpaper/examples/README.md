# live-wallpaper 案例图

两张都是同一张源图（832×1248）的输出，同一套脚本，唯一区别是**遮罩半径**与**亮度处理**。

## fail-panel-seam.jpg —— 失败：贴图感

- 想做什么：把竖图放进 16:9 画布，背景用同图虚化。
- 怎么错的：主体直接 `paste` 到虚化床上，没有羽化；背景还单独压到 ×0.72。
- 结果：中间一块**边缘笔直的矩形面板**，左右上下四条硬边，一眼看出是贴上去的。
- 复现：`sub` 高 0.97H、无 alpha 遮罩、`bed` 亮度 ×0.72。
- 处方见 `references/motion-and-composition.md` 第二节与第七节。

## ok-oval-focus.jpg —— 成功：景深焦点

- 同一张图，主体 0.99H，叠 `rx=0.52 / ry=0.57 / plateau=0.46` 的椭圆径向遮罩，背景 ×0.86 + 全局 vignette。
- 结果：清晰区收在她脸上并向四周柔化，观感是「镜头对焦在她身上」，不是「一张图放在背景上」。
- 该帧取自成品视频第 10 秒（`_check_mid10s.png`），3840×2160 缩到 1600×900。
